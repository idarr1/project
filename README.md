# 🚗 Автосалон — Веб-интерфейс сайта автосалона

Курсовой проект по дисциплине «Информационные технологии и программирование».  
Разработка клиентского веб-приложения автосалона с поиском, фильтрацией автомобилей, вкладкой для избранных авто и адаптивным интерфейсом.

🔗 GitHub Pages:  
https://idarr1.github.io/project/

---

# 📋 Техническое задание

## Общие требования

Назначением курсовой работы является разработка современного адаптивного веб-интерфейса для сайта автосалона, обеспечивающего удобное взаимодействие пользователя с каталогом автомобилей и функциональными возможностями сайта. 

Сайт предоставляет пользователю возможность просмотра каталога автомобилей, поиска и фильтрации моделей, добавления автомобилей в избранное, а также отправки пользовательской заявки через форму обратной связи.

В процессе разработки были применены современные технологии веб-разработки: HTML5, CSS3 и JavaScript. Для хранения пользовательских данных использовалась технология localStorage.

---

## Функциональные требования

### Обязательные:
- отображение каталога автомобилей;
- просмотр карточек автомобилей;
- поиск автомобилей по названию модели;
- фильтрация по заданным параметрам;
- добавление автомобилей в избранное;
- оформление заявки через форму обратной связи;
- адаптивное отображение интерфейса;
- валидация формы;
- сохранение данных в localStorage.

### Желательные:
- сортировка автомобилей;
- реализация анимационных эффектов;
- динамическое обновление интерфейса.

---

## Технические требования

Сайт функционирует на современных компьютерах и мобильных устройствах. Минимальные технические характеристики: процессор от 1.6 ГГц, ОЗУ от 512 МБ. Рекомендуемое разрешение экрана — от 1024×768 пикселей. 

---

## Программные требования

Сайт работает в современных браузерах:
- Google Chrome;
- Mozilla Firefox;
- Microsoft Edge;

Разработка выполнялась в Visual Studio Code с использованием Git и GitHub. Публикация проекта осуществляется через GitHub Pages.
